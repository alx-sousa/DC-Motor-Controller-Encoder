# REV A Hardware

REV A is the first PCB revision of the DC Motor Controller with Encoder.

## Main functional blocks

- 12 V input and protection
- TPS54302 12 V → 5 V buck converter
- DRV8871 motor driver
- incremental encoder A/B interface
- removable ESP32-C6 Super Mini
- 2-layer GND structure with stitching vias
- PowerPAD thermal-via implementation
